Privacy policy

CuteMute collects nothing, sends nothing, and has no way to do either.

Applies to CuteMute 1.0.0 and later, for the Microsoft Store package and the standalone CuteMute.exe alike.

No network access

CuteMute makes no outbound connections of any kind. No telemetry, no analytics, no update check, no crash reporting, no licence check, no “anonymous usage statistics”. It contains no HTTP client and opens no socket. The Store package declares no internetClient capability, so Windows itself would prevent it even if the code tried.

This is not a policy that could quietly be reversed in a later build. Any version that changed it would have to change this page too, and the commit that did so would be public.

Keystrokes

CuteMute installs a low-level Windows keyboard hook. That is how a mute key can work while another application has focus, and it means the program does see keystrokes, so it is worth being exact about what happens to them.

Each keystroke is compared against your configured hotkey and then discarded. Nothing is stored, buffered, logged, aggregated, or transmitted. There is nowhere for it to go: the program has no network access, and the only file it writes is the settings file below. The comparison lives in cutemute/hotkey.py, which is deliberately short so that this claim can be checked rather than merely believed.

Microphone

CuteMute sets and clears the mute flag on your capture devices through Windows Core Audio. It never opens an audio stream, so it cannot record, and there is no code in it that could.

What it stores, and where

One file, on your machine only:

%APPDATA%\CuteMute\config.json

It holds your settings — the hotkey, the badge's size, position and opacity, and the handful of switches in the settings window. No identifiers. No history of what you muted or when. No keystrokes. In the Store package this file lives inside the app's own per-user storage, and uninstalling removes it with the app.

The standalone .exe also writes three per-user entries so Windows can find it — a Start menu shortcut, a Win+R name, and an installed-apps entry — each containing only the program's path, name, version and publisher. CuteMute.exe --uninstall removes all of them. The Store package writes none of these; the package declares them instead, and Windows removes them on uninstall.

Children

CuteMute is a general-purpose utility, is not directed at children, and collects no personal information from anyone.

This website

This site is two static HTML files with no third-party scripts, no analytics, no cookies, and no fonts or images loaded from other hosts. It is served by GitHub Pages, and GitHub may log requests to it as described in GitHub's privacy statement. Downloads come from GitHub Releases, which GitHub also logs.

Releases

Release signing writes a record to Sigstore's public transparency log. Those records are permanent and public, and they identify the GitHub Actions workflow that signed the release — not a person, and no email address. See the code signing policy.

If you find anything in the source that contradicts this page, that is both a bug and a security issue, and it is the most useful report this project can receive. Please raise it as described in SECURITY.md.
